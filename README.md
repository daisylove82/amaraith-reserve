## 🚀 How to Deploy to GitHub Pages

### Step 1: Enable GitHub Pages
1. Go to your repository: https://github.com/daisylove82/amaraith-reserve
2. Click **Settings** tab (top menu)
3. Select **Pages** from the left sidebar

### Step 2: Configure Deployment Source
- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)
- Click **Save**

### Step 3: Wait for Deployment
- GitHub will automatically deploy your site
- Wait 2-3 minutes for the deployment to complete
- You'll see a green checkmark when ready

### Your Website URL
🎉 **Your site is now live at:** https://daisylove82.github.io/amaraith-reserve/

## 🎨 Customization

### Update Villa Information
Edit the villa card sections in `index.html`:
```html
<article class="villa-card">
    <img src="your-image-url" alt="Villa Name">
    <div class="villa-info">
        <h3>Villa Name</h3>
        <p>Villa Type</p>
        ...
    </div>
</article>
```

### Modify Colors
Primary colors used:
- **Gold:** `#CBA266`
- **Teal:** `#00778C`
- **Black:** `#000`

### Update Contact Details
Find and replace in footer section of `index.html`
